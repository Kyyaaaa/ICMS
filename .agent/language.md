1. **Quy định ràng buộc ngôn ngữ:** Quy tắc phân chia rõ ràng (Prompt tự do, Code 100% tiếng Anh, Comment 100% tiếng Việt).

3. **Ví dụ thực tế minh họa:** Đưa ra ví dụ trực quan về Backend (ExpressJS API xử lý cơ sở dữ liệu) và Frontend (React Component cho thiết bị mạng) giúp AI hiểu chính xác yêu cầu định dạng đầu ra.
4. **Bộ tiêu chí tự kiểm tra (Checklist):** Ép AI phải rà soát lại các biến lai tạp (như `layThongTin`) và đảm bảo giữ chuẩn form trước khi hiển thị kết quả cho bạn.
